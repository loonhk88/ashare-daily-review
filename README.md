# A股每日复盘 · 静态归档站

复刻 `ashare-daily-review-64356.app.workbuddy.host` 的网站：**静态归档站 + 12 章固定结构 + 涨红跌绿口径**，
全部数据来自公开数据接口，**取不到即整条删除，绝不编造**。

## 快速开始

```bash
cd ashare-review
./run.sh 2026-10-14          # 采集 + 构建（指定交易日）
./run.sh                     # 采集 + 构建最近交易日
python3 -m http.server 8099  # 本地预览 → http://127.0.0.1:8099
```

产物：
- `index.html` — 归档首页（自动列出所有已生成日期）
- `reviews/YYYY-MM-DD.html` — 单篇复盘（12 章）
- `data/YYYY-MM-DD.json` — 原始结构化数据（可追溯）
- `data/YYYY-MM-DD.analysis.json` — 分析段（人工/半自动撰写）


## 数据源与降级链（实测结论）

本机 `push2.eastmoney.com` 与 `push2his.eastmoney.com` **长期被限流（RemoteDisconnected）**，
因此采集器为每一项数据都配置了备用源，并如实记录降级情况（第 12 章展示）。

| 数据项 | 主源 | 备用源 | 实测 |
|---|---|---|---|
| 指数行情 | 东财 push2 | **腾讯 qt.gtimg.cn** | 东财常失败 → 腾讯稳定 |
| 日 K 线 | 东财 push2his | **新浪 getKLineData** | 东财常失败 → 新浪稳定（含当日） |
| 全市场涨跌家数 | 东财 push2 | **新浪全市场分页** | 新浪可取 5573 只 |
| 涨停/跌停/炸板 | **东财 push2ex** | — | 稳定可用，字段最全 |
| 行业/概念板块 | 东财 push2 | **东财 MCP 连接器 / 本地库** | push2 失败 → 连接器可用 |
| 个股资金流 | **东财数据中心**（PRIME_INFLOW） | 东财 push2 → 新浪 MoneyFlow | 数据中心稳定且字段全 |
| 龙虎榜/机构席位 | **东财 datacenter-web** | — | 稳定可用 |

### 关键口径（务必遵守）

1. **涨停/跌停**：以东财涨跌停专题为准。跌停池**不含部分 ST 股**（接口过滤），故实际跌停数可能略高。
2. **连板数**：使用「几天几板」原始字段（N 天内累计涨停 M 次），**不用「前一日 + 1」推算**。
   注意 `lbc`（连板数）与 `zttj`（几天几板）**经常不一致**：
   某股 13 天涨停 9 次但当日是断板后重新首封时，`lbc=1`、`zttj=13/9`。
   页面显示时两者不一致一律标注「N天M板」，避免把累计板数误读为连续高度。
3. **封成比** = 封单额 ÷ 当日成交额 × 100%（本文计算口径，与行情软件可能不同）。
4. **主力净额**：个股（新浪）与板块（东财）口径不同，**绝对数值不可跨表比较**。
5. **跌停/涨停价格**：东财专题 `p` 字段为**价格 × 1000**（如 20970 → 20.97），已用腾讯行情交叉验证。

### 历史日期的限制（重要）

实时行情接口（腾讯/新浪快照）**只返回最新交易日**的数据。因此：

- 采集历史日期时，`collect.py` 会检测该日期是否等于今天；
- 若不等，**指数改由日 K 线还原**（成交额、换手率不可得，标 `—`）；
- **全市场涨跌家数无法回溯**，该指标整条删除并在页面说明；
- 涨停/跌停/龙虎榜/板块等**有历史接口的数据不受影响**，正常采集。

## 添加新的一天

```bash
# 1. 采集（自动降级）
python3 scripts/collect.py 2026-10-15

# 2. 若板块缺失（push2 被限），从连接器取：
#    调 MCP 的 get_sector_list(industry/concept)，把结果存成文本，然后：
python3 scripts/import_mcp.py <spill.txt> --as industry
python3 scripts/import_mcp.py <spill.txt> --as concept
python3 scripts/merge_mcp.py data/2026-10-15.json \
    --industry tools/cache/industry.json --concept tools/cache/concept.json

# 3. 撰写分析段（第 1/9/10/11 章）
cp data/2026-10-14.analysis.json data/2026-10-15.analysis.json
#    ... 编辑 ...

# 4. 构建
python3 scripts/build.py 2026-10-15
#    或重建全部：python3 scripts/build.py --all
```

## 设计特性

- **单页零外部依赖**：CSS/JS 全部本地文件，双击即可离线打开

- **纯 CSS 可视化**：涨跌分布条形图、板块涨幅条、连板梯队卡、情绪温度计
- **响应式**：980px / 640px 断点，移动端已验证
- **导航滚动高亮**、返回顶部、打印样式
